# Avisos de las calculadoras de R

Tutorial para el equipo de las calculadoras de Actuaria: el bloque que se agrega en la ui de cada app de Shiny para que actuaria.com sepa cuándo la calculadora está lista (pantalla de carga) y cuándo alguien calcula (evento `use_calculator` de GA4).

- Página: https://renatopuente-ux.github.io/actuaria-calculadoras-avisos-r/
- Bloque para copiar: [`bloque-avisos.R`](bloque-avisos.R)
